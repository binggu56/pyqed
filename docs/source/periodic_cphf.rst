Periodic CPHF
=============

PyQED provides a dependency-free static coupled-perturbed Hartree--Fock
(CPHF) solver for converged periodic KRHF references.  The public name follows
the conventional PySCF terminology: the reference is KRHF, while its orbital
response equations are called periodic CPHF.

Equations
---------

For perturbation component :math:`x` with crystal momentum :math:`\mathbf q`,
the canonical occupied--virtual response satisfies

.. math::

   (\epsilon_{a,\mathbf k+\mathbf q}-\epsilon_{i\mathbf k})
   U^x_{ai}(\mathbf k,\mathbf q)
   + \left[G_{\mathbf q}(P^x_{\mathbf q})\right]_{ai,\mathbf k}
   = -\left(
       F^{x,\mathrm{explicit}}_{ai}(\mathbf k,\mathbf q)
       - \epsilon_{i\mathbf k}S^x_{ai}(\mathbf k,\mathbf q)
     \right).

Here :math:`G_{\mathbf q}(P^x_{\mathbf q})` is the q-resolved induced
Coulomb--exchange potential.  For a general non-self-opposite q point, the
physical first-order density couples the :math:`+\mathbf q` and
:math:`-\mathbf q` orbital responses:

.. math::

   P^x_{\mathbf q}(\mathbf k+\mathbf q,\mathbf k)
   = C_{\mathbf k+\mathbf q}U^x_{\mathbf q}(\mathbf k)
     f C^\dagger_{\mathbf k}
   + \left[
       C_{\mathbf k}U^x_{-\mathbf q}(\mathbf k+\mathbf q)
       f C^\dagger_{\mathbf k+\mathbf q}
     \right]^\dagger,

with closed-shell occupations :math:`f_i=2`.  At :math:`\mathbf q=0`, this
reduces to

.. math::

   P^x_{\mathbf k}
   = C^x_{\mathrm{occ},\mathbf k} f C^\dagger_{\mathrm{occ},\mathbf k}
   + C_{\mathrm{occ},\mathbf k} f
     C^{x\dagger}_{\mathrm{occ},\mathbf k}.

When the AO basis moves, the occupied--occupied gauge is

.. math::

   U^x_{ij,\mathbf k}=-\frac{1}{2}S^x_{ij,\mathbf k}.

The implementation solves these equations with matrix-free GMRES.  It
represents complex amplitudes through their real and imaginary components, so
the density map containing both response sectors is treated as a real-linear
operator.  Induced J/K matrices reuse the active KRHF backend.  The
:math:`\mathbf q=0` path supports reciprocal Coulomb, Ewald, and periodic GDF;
nonzero q points use periodic GDF.

API
---

``KRHF.response()`` and ``KRHF.CPHF()`` return the same response driver.  The
input contains one explicit AO Fock derivative per perturbation component and
k point:

.. code-block:: python

   import numpy as np

   h1 = np.asarray([
       [[0.10, 0.03], [0.03, -0.04]],
   ])
   response = mean_field.response().kernel(h1, tol=1.0e-10)

   first_order_density = response.dm1[0]
   first_order_orbitals = response.mo_coeff1[0]

For a commensurate nonzero q point, ``h1_q[k]`` has AO rows at
:math:`\mathbf k+\mathbf q` and columns at :math:`\mathbf k`.  The driver
constructs the Hermitian-conjugate :math:`-\mathbf q` perturbation and solves
both response sectors together:

.. code-block:: python

   qpoint = mean_field.with_df.qpts[1]
   response = mean_field.response().kernel(
       h1_q,
       s1=s1_q,
       qpoint=qpoint,
       tol=1.0e-10,
   )

   density_q = response.dm1
   amplitudes_minus_q = response.mo1_minus_q

The lower-level PySCF-shaped interface is also available:

.. code-block:: python

   from pyqed.qchem.pbc.scf import cphf

   mo1, mo_e1 = cphf.solve(
       fvind,
       mo_energy,
       mo_occ,
       h1_mo,
       s1=s1_mo,
   )

The finite-field validation and diagnostic figure are reproducible with

.. code-block:: console

   PYTHONPATH=. python examples/pbc_cphf.py \
       --output /private/tmp/pbc_cphf_validation.pdf

Scope
-----

The current solver supports static, closed-shell, integer-occupation response
at :math:`\mathbf q=0` and commensurate nonzero q points on the SCF k mesh.
General q points use a coupled :math:`\pm\mathbf q` solve; self-opposite
zone-boundary points use the reduced single-sector form.  Nonzero-q response
currently requires periodic GDF.  Both the explicit Fock perturbation and the
moving-basis overlap perturbation are retained; their :math:`-\mathbf q`
partners are generated by Hermitian conjugation.

The Gamma-point electronic response is connected to the CPHF-relaxed
:doc:`periodic_phonons` Hessian.  Commensurate finite-q analytic nuclear
perturbations are available through ``commensurate_gdf_q_derivative`` using a
temporary one-twist commensurate supercell.  This is a correctness-oriented
bridge rather than a primitive-cell DFPT kernel, so the finite-displacement
supercell driver
remains the production phonon-dispersion path.  Metallic occupation and
Fermi-level response are also outside the present scope.

The commensurate driver uses the directional gradient interface, which
contracts one complex traveling-wave displacement while derivative stages are
produced.  This lowers retained Cartesian AO derivative storage from three
full tensors to at most two; the commensurate-supercell GDF factors remain the
main large-system memory limit.

The temporary supercell preserves the primitive physical reciprocal reach.
For primitive one-electron reciprocal bound :math:`n_{c,i}` and supercell
multiplier :math:`L_i`, its anisotropic bound is

.. math::

   n_{c,i}^{\mathrm{SC}}=L_i n_{c,i}.

The inversion-symmetric GDF grid instead follows

.. math::

   n_{c,i}^{\mathrm{SC}}
   =L_i n_c+\left\lfloor\frac{L_i}{2}\right\rfloor,
   \qquad M_i^{\mathrm{SC}}=2n_{c,i}^{\mathrm{SC}}+1,

which represents every primitive :math:`G+q` vector and retains both Nyquist
endpoints on even meshes so self-opposite derivatives remain adjoint symmetric.

Validation
----------

``tests/test_pbc_cphf.py`` checks an exactly solvable two-level model,
real-linear complex response, reciprocal and GDF finite-field derivatives,
multi-k density conservation, a self-opposite zone-boundary response, and a
general coupled :math:`\pm\mathbf q` response against full block finite-field
SCF.  The general-q finite-field test includes an off-diagonal overlap
perturbation and therefore validates the Pulay response explicitly.
