$\mathrm{D}_3^+$ benchmarks. Build with:

```bash
pdflatex main.tex

```

under `OneDrive/data/pyqed/ethylene_ci_periodic_2d`, outside the repository.
The external FCI/MACE database and isotope dynamics runs are under
`OneDrive/data/h3plus_fci_augccpvdz`.
